# Research Assets

This directory contains exploratory material that is intentionally not part of the supported package API.

## Contents

- notebooks for interactive inspection and visualization
- ad hoc evaluation scripts
- historical analysis artifacts preserved for reference

## Usage Expectations

- these files may assume local datasets or checkpoints
- they are not guaranteed to stay in sync with the supported CLI surface
- if one of these workflows becomes important enough to maintain, migrate it into `src/ecgtwin/` and document it in `docs/`
