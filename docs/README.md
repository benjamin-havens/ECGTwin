# Documentation Index

This directory contains operator and maintainer documentation for the refactored ECGTwin repository.

## Documents

- `architecture.md`: how the package is organized and how data flows through it
- `cli.md`: the supported command-line interface and when to use each command
- `configuration.md`: the YACS configuration tree, naming conventions, and override examples
- `development.md`: guidance for extending or modifying the repo safely
- `mimic_data.md`: dataset-specific preparation notes

## Reading Order

If you are new to the repo:

1. Read `architecture.md`
2. Read `configuration.md`
3. Use `cli.md` for the workflow you want to run
4. Use `development.md` if you are changing code
